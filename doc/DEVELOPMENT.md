## 运行与交付

使用 Node.js 24+、npm；本轮 Windows 环境为 Node.js 24.20.0、PowerShell 7、UTF-8。

```bash
npm ci
npm run dev
npm test
npm run build
npm run preview
npm run package
```

- `dist/index.html` 与 dist 目录：普通静态站点，部署时保留整个目录。
- `dist/星域节点.html`：图片、CSS、JavaScript 内嵌的离线单文件。
- `dist/运行说明.txt`：玩家启动与操作说明。
- `artifacts/releases/星域节点-前沿行动试玩.zip`：离线作品、说明与 source/ 源码，不含依赖、本机存档、Git 历史和诊断采样。

单文件由 `scripts/build-offline.mjs` 生成并检查依赖闭合；Windows 打包脚本检查输出路径属于本项目。新增外部资源时必须同步扩展离线生成器。

## 当前规则

### 空间经济与自由建造

采矿站绑定矿脉占用范围，每个矿脉只容纳一座存活采矿站；其他设施没有固定塔位。开采依赖己方、存活、连通及实际能量。矿脉收益随效率升级有界增长，不按旧模式的等级、超载和邻居数量无限叠加。低速应急补给为每局一份，不随核心数量叠加；击杀仅补充资源。

样板关的回收基于设施实际投资，包含折扣后的建造、升级、进化与核心扩展；免费初始设施的原始投资为零。回收不会返还晶体或科研费用。研究、链路和扩展同样计入本局支出，结算净投入扣除已经回收的资源，避免折扣建造与名义退款产生套利。

施工与自动验证使用相同付费命令、放置碰撞、已探索区域和接线限制。固定布局脚本只在显式 benchmark 模式运行，不给正常玩家指定塔位。

### 供电与战斗

模拟使用 1/60 秒固定步长，每 500ms 处理一次供能和经济；加速统一推进模拟。标签页隐藏会在正常模式暂停。

常规输能先按容量与压力差提出均衡需求，再按节点耦合强度限步，并公平分摊源储备和目的空间。这样避免两端储能反复交换，以及高分支电网过冲。物理链路和虫洞通道都接受容量约束，同一对虫洞内自由布置的多个中继共享通道带宽，edge.energyFlow 记录实际方向与输送量；常规输送守恒，配置中的增幅链路、主动产能及联动独立结算。

中继升级提升储能和输送效率。能量站真实产能及环境倍率由 graph.ts 的统一函数计算，界面与模拟共用；核心科研增产实际生效。无目标弹丸武器、无人机和无受损友军的维修站不消耗对应工作能量。

炮塔、狙击塔的选敌、弹丸碰撞和有效射界读取同一遮挡模型；普通炮塔射程小幅随等级成长，进化与研究也保持局部覆盖。无人机按自身配置进行越障范围打击。伤害统一应用护盾减免，死亡奖励只结算一次；真实攻击记录驱动光效，装饰随机不消耗游戏随机序列。

### 侦察与任务

己方核心及通电、连通的设施提供实时视野。探索记忆用于规划建造，失去供电后撤销实时敌情；隐匿者可被信标或雷达提前发现，接触攻击时短暂暴露。天气影响侦察，使用可复现的游戏随机序列。

`frontier.ts` 同时驱动 HUD、地图标记与主任务判定：远端矿物独立累计，消费资源不扣目标进度；观测或充能只在有效连接与能量充足时推进。断电暂停数据获取，部分与已完成数据均在回收、重建后保留。显示使用已结算工作状态，避免刚扣除任务能量就误报停工。核心全部失守优先判负。

岩隙采集要求基地外开采，雾海观测可在三个地点中任选两处并允许逐处完成，双域跃迁使用有先后关系的校准与充能。所有地点和精确参数以 [frontier-levels.ts](../src/data/frontier-levels.ts) 为准。

## 设施辨识与实际验证 · 2026-10-20

23 类设施（含核心）采用独立的透明图片，替换共用灰蓝底座、分组复用上装的旧实现。每类先确定功能轮廓及颜色，再以红色短管炮为风格参照生成同一套素材。炮塔、狙击塔、拦截器使用宽短炮、细长轨道炮、导弹巢；中继、信标、雷达使用窄身导电叉、镜头卫星、扇面天线。回声塔重做为侧向三道波纹，避免与马蹄磁力塔重形。

功能色、形象及实际 alpha 边界以 [facility-art.ts](../src/data/facility-art.ts) 为准；配置卡、建造色条和航图保持相同功能色，不受界面换肤影响。设施断电仍保留主体颜色，满员时未选卡片也保留图像与名称的完整可读性。世界、建造栏、详情与标题由同一 `drawFacility` 绘制。启动完成图片解码与 256 像素缓存后再进入首屏；素材错误给出可重载的失败提示，不切回旧模型。武器围绕节点转向，方向来自实际开火目标，等级与进化另用小型标记表达。

生成采用内置 ImageGen、真实透明背景；只转换为无损 WebP，逐像素核对全部 alpha 及非完全透明像素的 RGB，保留原始画面。完全透明处无效 RGB 由编码器清理。共用提示词、逐类提示词、风格参照、源图及交付图 SHA-256 记录在 [素材记录](../public/art/facilities/credits.json)。素材不是人工逐像素绘制的原画。
