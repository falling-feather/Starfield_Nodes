# 星域节点 · Starfield Nodes

已参与2026数媒竞赛。当前参赛源码保存在本仓库，后续从GitHub克隆继续开发。

自由建造设施，选择值得经营的前沿，让供电、侦察与火力组成一张能够运转的防御网络。

TypeScript + Canvas 2D 桌面策略塔防。当前入口为三张「前沿行动」样板关，历史九关与已有通关档案保留。

设施采用 23 类独立透明素材：固定功能色、不同的机械轮廓，战场、建造栏与配置卡保持一致。例如红色短管炮、橙色细长轨道炮、蓝色导弹巢分别表示炮塔、狙击塔和拦截器。

[查看设施图谱与小尺寸对照](doc/images/14-facility-identities.jpg)（2026-10-20 历史素材校样）。

2026-10-23界面已按分页与信息层调整，已交9张本轮真实运行图待独立验收。当前操作、自动验证及未覆盖范围见[开发说明](doc/DEVELOPMENT.md)；历史图片保留，不代表本轮布局。

## 直接试玩

解压「星域节点-前沿行动试玩.zip」，用桌面版 Edge 或 Chrome 打开根目录的「星域节点.html」。也可在本项目构建后打开 `dist/星域节点.html`。脚本、样式、背景及设施素材已内嵌，不需要安装 Node.js 或启动服务器。

建议使用 1024×600 或以上横向窗口，1440×900 的规划空间更充裕。开始航行后，三张样板关均可直接选择。

| 行动 | 主任务 | 主要取舍 |
| --- | --- | --- |
| 岩隙采集 | 从基地外矿脉取得任务所需矿物 | 安全浅矿、富矿前哨与岩隙截击 |
| 雾海观测 | 恢复任意两处观测阵列 | 并行布网、逐处观测与回收转场 |
| 双域跃迁 | 依次恢复彼岸校准站与星门 | 投资跨域主干，或建设远端独立核心 |

炮塔、供电站与线路仍可自由布局。采矿站可以在矿脉范围内选择位置，每处矿脉容纳一站。任务数据在断电、回收、重建后保留；样板关按设施实际投入返还 75% 的回收资源。

先按 **P** 暂停规划。遇到未知星域时，让前沿信标接入并实际充电，再继续扩张；暂停中的冷设施不会立即产生视野。

配置清单支持跨页选择与定位，任务简报、布局取舍和星图可切换查看。局内建造费用与无效原因显示在固定反馈栏。

## 基本操作

| 操作 | 默认方式 |
| --- | --- |
| 建造 | 底部设施卡或数字键，在已探索区域放置 |
| 接线 | 拖拽两个己方设施；新设施也可付费「接入最近线路」 |
| 接管 | 侦察到废弃设施后，选中并接管 |
| 升级 / 回收 | 选中设施，U / X，或点击详情按钮 |
| 观察前沿 | 任务面板「定位」、顶部「全域」、右下航图 |
| 平移 / 缩放 | Ctrl + 左键拖拽 / 滚轮 |
| 暂停 / 速度 | P / G，暂停时仍能建造接线 |
| 研究 / 手册 | T / H，面板打开时自动暂停 |
| 成就 / 联动 / 按键 | A / Y / K |
| 航行菜单 / 静音 | Esc / M |
| 结算 | Enter 返回行动列表，R 快速重开 |

已探索地形会被记住，实时敌情需要供电侦察。岩带遮挡炮塔与狙击塔的直射，选中时显示实际有效射界；无人机提供越障范围支援。局内研究在本次行动生效。

档案存储在当前浏览器本机。不同浏览器、网页地址或离线文件位置可能使用独立档案；作品没有在线账号或云同步。基础教学保留在「历史航线 → 初始星域」。

## 开发与打包

Node.js 24+；Windows 文件操作使用 PowerShell 7、UTF-8。

```bash
npm ci
npm run dev
npm test
npm run build
npm run preview
npm run package
```

`build` 生成常规静态站点及离线单文件；`package` 生成 `artifacts/releases/星域节点-前沿行动试玩.zip`，含离线作品、运行说明和可重建源码。本次将当前参赛版本的源码归档到main，未另分配产品版本号。
